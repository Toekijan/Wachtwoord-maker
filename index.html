Wachtwoord Maker

Zelfde naam + zelfde wachtwoord = altijd dezelfde code. Alles gebeurt lokaal in je browser.

    Je wachtwoord en de code worden nooit opgeslagen of verstuurd. De code wordt elke keer opnieuw berekend uit naam + wachtwoord (PBKDF2-SHA256, 600.000 rondes). Onthoud dus je wachtwoord en de exacte schrijfwijze van de naam (hoofdletters en spaties aan de randen worden genegeerd). "Knippen" kopieert de code en wist hem van het scherm.

    Wel onthoudt de app op dit apparaat welke lengte je het laatst koos voor een combinatie van naam + wachtwoord, onder een sleutel die niet naar je naam of wachtwoord terug te rekenen is. De laatste 5 appnamen worden leesbaar bewaard voor het uitklapmenu; je wachtwoord nooit. Op een ander apparaat kies je de lengte dus één keer opnieuw.
