Wachtwoord Maker

Zelfde naam + zelfde wachtwoord = altijd dezelfde code. Alles gebeurt lokaal in je browser.

Er wordt niets opgeslagen of verstuurd. De code wordt elke keer opnieuw berekend uit naam + wachtwoord (PBKDF2-SHA256, 600.000 rondes). Onthoud dus je wachtwoord en de exacte schrijfwijze van de naam (hoofdletters en spaties aan de randen worden genegeerd). "Knippen" kopieert de code en wist hem van het scherm.
